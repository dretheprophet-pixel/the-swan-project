# The Swan Project

A hybrid LOST-themed codex + Dharma terminal that reveals a unique daily lore entry inspired by the show’s mythology, stations, characters, mysteries, and personal reflections.

## Features (v1)
- Daily lore entry (date-seeded)
- Hybrid UI: Dharma terminal + island codex
- Station-of-the-day mode
- Numbers mode (4, 8, 15, 16, 23, 42)
- Fail-safe key for rare entries

## Tech Stack
- React + Vite
- TailwindCSS
- JSON data store
- Date-seeded logic

## Roadmap
- v1: Terminal + Codex hybrid UI
- v2: Audio + glitch animations
- v3: Island map mode
- v4: Personal LOST reflections mode
